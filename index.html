Dying ReLU — ReLU의 반대 문제

Experiment 3에서 ReLU가 Vanishing Gradient를 피하는 것을 봤습니다. 그런데 ReLU에는 반대 문제가 있습니다. 입력이 음수면 출력도 기울기도 0이라, 한번 죽은 뉴런은 다시 살아나지 못합니다. 학습률을 키워가며 죽은 뉴런이 얼마나 늘어나는지 봅니다.

도움말

이 시뮬레이터는 외부 라이브러리 없이 순전파·역전파를 직접 구현했습니다. 모든 계산은 브라우저에서 실행되며 서버로 데이터를 보내지 않습니다.

컨트롤

데이터셋
Linear·XOR·Circle·Spiral. 아래로 갈수록 어렵습니다.
Hidden layer 수
0이면 Single Perceptron이 되어 직선 경계만 그릴 수 있습니다.
Neurons per layer
층마다 뉴런 개수. 많을수록 표현력이 커지지만 과적합 위험도 커집니다.
활성화 함수
Sigmoid·Tanh·ReLU. 출력층은 이진 분류이므로 항상 Sigmoid입니다.
Learning rate
너무 작으면 느리고, 너무 크면 발산합니다. Experiment 2에서 확인할 수 있습니다.
Batch size
1이면 확률적 경사하강법, 전체면 배치 경사하강법입니다.

그래프 읽는 법

결정 경계
색이 모델이 예측한 확률입니다. 파랑 0 ↔ 빨강 1, 흰색이 0.5(경계)입니다.
학습 곡선
Loss는 Binary Cross-Entropy입니다. 로그 스케일이라 작은 변화도 보입니다.
Layer별 Gradient Magnitude
역전파에서 각 층이 받은 |dW|의 평균입니다. 왼쪽이 입력에 가까운 층입니다. 왼쪽으로 갈수록 급격히 작아지면 Vanishing Gradient입니다.
Gradient 변화
학습이 진행되며 각 층의 기울기가 어떻게 변하는지 봅니다. 수렴하면 모든 층이 함께 0으로 가므로, 비교는 학습 초기 구간을 봐야 합니다.
Activation 분포
값이 양 끝에 몰리면 포화입니다. Sigmoid 도함수는 최대 0.25라 층을 지날 때마다 기울기가 최소 4분의 1로 줄어듭니다.

역전파 검증 (지금 실행)

이 시뮬레이터의 역전파가 맞는지 이 자리에서 확인할 수 있습니다. 각 가중치를 아주 조금(±10⁻⁵) 흔들어 손실이 실제로 얼마나 변하는지 재고, 역전파가 계산한 기울기와 비교합니다. 둘이 일치하면 구현이 맞습니다.

구현 메모

검증
역전파가 맞는지 수치적 gradient check로 확인했습니다 (test/gradcheck.js, 상대오차 10⁻⁷ 수준).
재현성
데이터와 가중치 초기화에 고정 시드를 써서 같은 설정이면 항상 같은 결과가 나옵니다.
비교의 공정성
Sigmoid와 ReLU를 비교할 때 같은 데이터·같은 시드·같은 학습률을 사용합니다. 가중치 초기화는 Gradient 분석 탭에서 고를 수 있습니다 — 동일(Xavier)은 활성화 함수 효과만 분리하는 통제 비교, 각자 표준(Xavier/He)은 실무에서 쓰는 방식대로의 비교입니다.
성능
계산은 setTimeout으로, 렌더링은 주기적으로 분리했습니다. requestAnimationFrame에 묶으면 창이 가려졌을 때 학습이 멈춥니다.
